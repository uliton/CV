# CV API на uliver

Сервіс `cv-backend.service` слухає `127.0.0.1:19391` на uliver. Для роботи з локальним фронтендом відкрий тунель в окремому терміналі.

```bash
ssh -NT -o ExitOnForwardFailure=yes -L 127.0.0.1:19391:127.0.0.1:19391 uliver
```

Запусти або перезапусти фронтенд, щоб підхопити проксі `/api`.

```bash
cd /Users/uliton/Documents/CV/front
npm ci
npm start
```

Відкрий [localhost:3000](http://localhost:3000/). Вхід доступний з футера або за [прямим посиланням](http://localhost:3000/#/admin/login). Користуйся адресою `localhost`, щоб браузер і API використовували налаштований origin. Поки тестовий пароль лишається чинним, API доступний через SSH-тунель.

| Метод і шлях | Призначення |
| --- | --- |
| `GET /api/content` | Весь вміст CV одним JSON-об’єктом, версія в заголовку `ETag`. |
| `POST /api/auth/login` | Приймає JSON з `username` і `password`, встановлює JWT у захищену cookie на дві години. |
| `GET /api/auth/session` | Перевіряє сесію з cookie. |
| `POST /api/auth/logout` | Видаляє cookie браузера. |
| `PUT /api/content` | Зберігає весь оновлений документ. Потрібні cookie, дозволений `Origin` і останній `ETag` у `If-Match`. Відповідь `412` означає, що запис уже змінився. |

Адмінка має вкладки для профілю, освіти, самоосвіти, навичок, хобі та спорту, досвіду, портфоліо, контактів і назв пунктів навігації. У Portfolio можна додавати, редагувати й видаляти роботи. Опис роботи є необов’язковим. Збережені зміни лежать у `~/cv-backend/data/content.json`. При першому запуску джерелом слугує `front/src/mockData.json`. Збережений файл і налаштування в `~/cv-backend/config.env` зберігаються окремо від коду сервісу.

Команди для стану та журналу на uliver:

```bash
systemctl status cv-backend
sudo journalctl -u cv-backend -n 50
```

Для локального запуску самого API потрібен Node.js 20.12 або новіший. Скопіюй `.env.example` у `.env` і задай випадковий `CV_JWT_SECRET` довжиною щонайменше 32 байти. Команда `npm test` запускає інтеграційний тест на тимчасовому порту й у тимчасовій директорії.

Публічна збірка GitHub Pages читає вміст із `front/src/mockData.json`. Перед публікацією онови цей файл даними з `GET /api/content` через тунель і звір тексти та посилання. `npm run deploy` у папці `front` збирає цю версію сайту. Редагування CV через адмінку доступне в локальній версії.
